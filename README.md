# Movie Search App
Separate application for the minor project.

## Requirements covered
- Search movies using a public movie database API
- Movie posters and details
- Ratings/release information supported by API search results
- Invalid query handling
- Responsive UI
- ES6 arrow functions, destructuring, template literals and modules
- DOM manipulation, event handling and form processing
- Promises, async/await, Fetch API and error handling
- JSON/API response rendering

## Setup
1. Open `js/config.js`.
2. Replace `YOUR_OMDB_API_KEY` with your OMDb API key.
3. Run `index.html` using VS Code Live Server.
